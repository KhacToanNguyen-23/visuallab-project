# Phase 3: Frontend Landing Page, Role Selector & Google Login UI

**Goal:** Thiết kế Trang Giới Thiệu (Landing Page) hiển thị đầu tiên, bộ chọn Vai trò (Student/Teacher) và Nút đăng nhập Google.

---

## Deliverables

1. `RoleSelector.tsx`: Component chọn Học sinh / Giáo viên dạng Card trực quan.
2. `LandingPage.tsx`: Trang giới thiệu sản phẩm cao cấp (Hero banner, Tính năng 2D simulation, GDPT 2018, CTA nút Đăng nhập/Đăng ký).
3. `LoginPage.tsx`: Tích hợp `RoleSelector` vào Tab Đăng ký và thêm nút "Đăng nhập với Google".
4. `App.tsx`: Routing chính `/` -> `LandingPage`, `/login` -> `LoginPage`, `/dashboard` -> `DashboardPage`.
