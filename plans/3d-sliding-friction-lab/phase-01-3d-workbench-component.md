# Phase 1: 3D Three.js Workbench Component (FrictionWorkbench3D)

## Goal
Build `FrictionWorkbench3D.tsx` in `src/components/simulations/sliding-friction/`:
- Three.js WebGL scene with orbit controls & shadows.
- Wooden track bench & 3D rectangular wooden block.
- 3 Material Surfaces: Wood ($\mu = 0.25$), Mica ($\mu = 0.15$), Rubber ($\mu = 0.45$).
- Stackable 3D Slotted Chrome Weights (50g, 100g, 200g).
- 3D Spring Dynamometer with transparent tube, coiled spring, and pointer scale.
- 4 Dynamic 3D Force Vectors ($\vec{F}_{kéo}, \vec{F}_{ms}, \vec{N}, \vec{P}$) with arrow helpers.

## Verification
- Run `npm run build` in `frontend/` to confirm 0 compilation errors.
