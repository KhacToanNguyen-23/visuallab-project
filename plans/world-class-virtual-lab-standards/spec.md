# Feature Spec: World-Class Virtual Lab Interactive Enhancements

**Status:** Draft / Brainstormed & Planned
**Date:** 2026-09-12
**Target Area:** `frontend/src/components/workflow/`, `frontend/src/components/simulations/`

## 1. Context & Purpose
Nâng cấp các tính năng tương tác của phòng lab ảo VisualLab theo chuẩn thế giới (Labster, PhET, Tinkercad Circuits, Brilliant.org): Đồ thị động thời gian thực (Live Graphing), Phản hồi đa giác quan (Audio & Visual Overload/Spark Warnings), và Biểu đồ Năng lực Radar Chart 3 chiều.

## 2. Requirements & Scope

### P1 — World-Class Interactive Features (Phải làm ngay)
- [ ] **Live Graphing Panel (Đồ thị thời gian thực)**: Hiển thị đồ thị dao động/dòng điện $U-I$, $x-t$, $v-t$ chạy động thời gian thực bên cạnh bài lab.
- [ ] **Multimodal Overload Feedback**: Cảnh báo hình ảnh/âm thanh khi quá tải (bóng đèn cháy, vôn kế kim vượt thang đo).
- [ ] **Radar Chart Năng Lực 3 Chiều**: Hiển thị kết quả nộp bài dạng Radar Chart phân tích Thao tác - Sai số - Lý thuyết.

## 3. Success Criteria
- [ ] Học sinh thấy đồ thị vẽ tự động khi thay đổi tham số thí nghiệm.
- [ ] Màn hình nộp bài hiển thị biểu đồ phân tích năng lực rõ ràng.
