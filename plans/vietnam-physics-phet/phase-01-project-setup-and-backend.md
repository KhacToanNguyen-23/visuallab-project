# Phase 1: Project Setup & Java Spring Boot Backend API

**Goal:** Khởi tạo cấu trúc dự án Frontend (React + TypeScript) & Backend (Java Spring Boot) cùng với API danh mục bài học GDPT 2018.

---

## Deliverables

1. **Frontend Setup**: Khởi tạo ứng dụng React 18 + TypeScript + Vite/Canvas.
2. **Backend Setup**: Khởi tạo Spring Boot API project với Maven/Gradle.
3. **Curriculum API**: Endpoints trả về danh sách các lớp học (6-12) và chuyên đề Vật lý (Cơ, Nhiệt, Điện, Quang, Sóng, Hạt nhân).

---

## Tasks

- [ ] Khởi tạo dự án React TypeScript cho Frontend.
- [ ] Khởi tạo Java Spring Boot ứng dụng backend REST API.
- [ ] Định nghĩa Controller & Service trả về danh mục bài thí nghiệm theo chương trình GDPT 2018.
- [ ] Kiểm tra kết nối API giữa Frontend và Backend thành công.
