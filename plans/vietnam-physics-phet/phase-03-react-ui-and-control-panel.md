# Phase 3: React UI Component & Interactive Control Panel

**Goal:** Hoàn thiện giao diện điều khiển React, thanh linh kiện kéo thả, công cụ đo (Ampe kế, Von kế) và các nút điều khiển.

---

## Deliverables

1. **Toolbar Component**: Thanh chứa các linh kiện có thể kéo thả vào workspace.
2. **Measurement Tools**: Công cụ Ampe kế (đo dòng điện qua dây) và Von kế (hai đầu que đo điện thế).
3. **Control Panel**: Sliders tinh chỉnh thông số $U, R$, nút bấm Play/Pause/Reset.

---

## Tasks

- [ ] Tạo Sidebar/Toolbar chọn linh kiện điện (Pin, Bóng đèn, Điện trở, Dây, Ampe kế, Von kế).
- [ ] Thêm linh kiện Ampe kế và Von kế tương tác trên Canvas.
- [ ] Xây dựng Control Panel điều chỉnh điện áp Pin ($0 - 24V$) và Điện trở ($1 - 100\Omega$).
- [ ] Thử nghiệm tương tác đo đạc thực tế: kiểm chứng $I = U/R$ và mạch nối tiếp/song song.
