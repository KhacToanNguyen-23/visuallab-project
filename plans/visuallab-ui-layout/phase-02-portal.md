# Phase 2: Portal Dashboard

## User Stories Covered
- **[P1]** As a Student, I want to browse labs grouped by Grade (10, 11, 12) and Chapters...
- **[P1]** As a Student, I want to search for a lab by name directly from the Landing Page...

## Architecture & Approach
Build the `LandingPage.jsx` component. It will have a Hero section containing a prominent Search Bar. Below the Hero section, display 3 large Category Cards for "Vật Lý 10", "Vật Lý 11", "Vật Lý 12". Inside each card or below them, list mockup dummy labs that link to `/labs/1`.

## Steps
1. Create `frontend/src/pages/LandingPage.jsx`.
2. Implement a Hero section with a massive, centered Search input.
3. Implement a Grid layout for Grade categories.
4. Add dummy links to `/labs/1` to test the routing.
